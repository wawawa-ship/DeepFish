导入对话

搬到 DeepFish
方式一 · DeepSeek 官方导出包（最完整）
在 DeepSeek App 的「数据管理 → 导出所有历史对话」里下载 zip， 选中后可以一次性把全部对话搬过来，标题、提问、回答、思考都会保留。
方式二 · 粘贴对话文本
解析后可以点角色标签纠正「是谁说的」，确认无误再导入。
方式三 · 导入文件
支持通用 JSON（role/content 结构）与纯文本，自动识别格式。
方式四 · 分享链接
分享页有反爬与登录校验，成功率低；建议直接用方式一。

DeepFish

一个可自定义角色的 DeepSeek 客户端

开源与用途

本项目是一个 GitHub 免费开源项目，仅供个人学习与日常使用，不用于任何商业用途。

与官方的关系

DeepFish 是第三方客户端，与 DeepSeek 官方没有任何隶属或合作关系。你使用自己的 API Key，所有费用由你的 DeepSeek 账户结算。

角色形象

软件图标与默认头像使用的是 子午老师 设计的男性角色形象，已获得子午老师授权在本项目中使用。

数据说明

对话、角色、头像与背景全部保存在本机，不会上传到任何第三方服务器。卸载应用会一并删除，请及时导出备份。
